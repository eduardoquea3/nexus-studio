# Project Rules

- Use `kebab-case` for file names in the project.
- The only exception is files inside a `hooks/` folder, which may use `camelCase`.
- Do not modify files under `src/components/` unless the user explicitly names the exact file to inspect and change.

## Project Skills

- `release-workflow`: use for commit, push, tag, and release requests. It requires validation and confirmation gates before remote mutations.
